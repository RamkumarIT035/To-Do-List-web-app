# TaskFlow - To-Do List Web App

A modern, responsive To-Do List web application built using **HTML, CSS, and Vanilla JavaScript**.

TaskFlow allows users to create, edit, complete, search, filter, and delete tasks. Tasks are automatically saved using the browser's `localStorage`, so they remain available even after refreshing the page.

---

## ✨ Features

- Add tasks
- Select a date manually
- Edit / update tasks
- Delete tasks
- Mark tasks as Completed or Incomplete
- Search tasks
- Filter tasks by:
  - All
  - Active
  - Completed
- Clear completed tasks
- Display total task count
- Display active task count
- Display completed task count
- Display completion percentage
- Smooth animations
- Responsive design
- Save tasks using browser `localStorage`
- No page reload required
- Press **Enter** to add or update a task
- Press **Escape** to cancel editing
